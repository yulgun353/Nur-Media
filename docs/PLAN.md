# ئىلانچىلىق شىركىتى — ئۈچ تىللىق تور بېكەت + Dashboard لايىھە پىلانى

> ھۆججەت تىلى: ئۇيغۇرچە · ۋەرسىيە: v1.0 · تېخنىكا دەلىللەش كۈنى: 2026-08-26

---

## 1. مەقسەت

ئىلانچىلىق (reklama/marketing) شىركىتى ئۈچۈن، **ئۆزىنى تونۇشتۇرۇش (portfolio/corporate)** خاراكتېرلىك، كەسپىي كۆرۈنۈشلۈك تولۇق تور بېكەت ۋە ئۇنىڭ بىلەن بىرگە ئىشلەيدىغان **ئارقا بەت باشقۇرۇش سۇپىسى (Admin Dashboard)** ياساش.

ئۈچ ئاساسىي تەلەپ:

| # | تەلەپ | ئىجرا ئۇسۇلى |
|---|---|---|
| 1 | ئۈچ تىل: ئۇيغۇرچە / ئەرەپچە / ئېنگىلىزچە | ھەر بىر تىل ئۆز URL يولىدا (`/ug/`، `/ar/`، `/en/`)، ئورتاق تەرجىمە سىستېمىسى |
| 2 | ئۇيغۇرچىغا **UKIJ Ekran** فونتى | فونت ھۆججەتلىرى لايىھە ئىچىدە ساقلىنىدۇ (offline ئىشللەيدۇ) |
| 3 | ئارقا بەت Dashboard | كىرىش (login)، مەزمۇن باشقۇرۇش، ستاتىستىكا، تەڭشەكلەر |

## 2. فونت سىستېمىسى (دەلىللەنگەن)

فونت ھۆججەتلىرى لايىھە ئىچىگە (`assets/fonts/`) چۈشۈرۈلدى ۋە `fontTools` ئارقىلىق تەكشۈرۈلدى. سىرتقى CDN غا تايانمايمىز — شۇڭا تور بېكەت ئوفلاينمۇ توغرا كۆرۈنىدۇ.

| تىل | رول | فونت | ۋەزىن | تەكشۈرۈش نەتىجىسى |
|---|---|---|---|---|
| ئۇيغۇرچە | بارلىق تېكىست | **UKIJ Ekran** | 400 | 1014 گلىف، `GSUB` تە **init / medi / fina / isol / rlig / calt** بار → ھەرپ شەكلى ئۆزگەرتىش توغرا |
| ئۇيغۇرچە | ماۋزۇ / كۈچلۈك تېكىست | **UKIJ Ekran Bold** | 700 | family="UKIJ Ekran"، subfamily="Bold" → `<b>` ئۆزلۈكىدىن ئىشلەيدۇ |
| ئەرەپچە | ماۋزۇ | **Noto Kufi Arabic** | 500, 700 | ئەرەپ ھەرپلىرىنىڭ ھەممىسى بار |
| ئەرەپچە | ئادەتتىكى تېكىست | **IBM Plex Sans Arabic** | 400, 500, 600, 700 | ئەرەپ + لاتىن ھەرپلىرى تولۇق |
| ئېنگىلىزچە | ماۋزۇ | **Space Grotesk** | 500, 600, 700 | A–Z، a–z، 0–9 بار |
| ئېنگىلىزچە | ئادەتتىكى تېكىست | **Inter** | 400, 500, 600, 700 | لاتىن + تىنىش بەلگىلىرى تولۇق |

**نېمىشقا بۇ جۈپلەش؟** UKIJ Ekran، Noto Kufi Arabic ۋە Space Grotesk ئۈچىلىسى گېئومېتىرىك / ساپ سىزىقلىق ئۇسلۇبتا. ئۈچ تىل ئالماشقاندا كۆرۈنۈش "شىركەت كىملىكى" بويىچە بىردەك بولۇپ قالىدۇ.

CSS دىكى ئىشلىتىلىشى:

```css
/* تىلغا قاراپ ئۆزلۈكىدىن تاللىنىدۇ */
html[lang="ug"] { --font-body: "UKIJ Ekran", "Noto Naskh Arabic", serif; --font-head: "UKIJ Ekran", ...; }
html[lang="ar"] { --font-body: "IBM Plex Sans Arabic", ...; --font-head: "Noto Kufi Arabic", ...; }
html[lang="en"] { --font-body: "Inter", system-ui, ...; --font-head: "Space Grotesk", ...; }
body { font-family: var(--font-body); }
```

> ئۇيغۇرچىدە UKIJ Ekran بار كومپيۇتېرلاردا ئالدى بىلەن يەرلىك فونت ئىشلىتىلىدۇ (`local()` ئارقىلىق)، بولمىسا بىز ساقلىغان ۋېب فونت.

## 3. تېخنىكا تاللىشى

| قەۋەت | تاللاش | سەۋەب |
|---|---|---|
| مۇلازىمېتىر | **Node.js 20 + Express** | build قەدىمى يوق، ئاسان ئىجرا قىلىنىدۇ، بىر پورتتا ھەم ئالدى بەت ھەم API |
| ساندان | **JSON ھۆججەت (`data/db.json`)** + ئاتوملۇق يېزىش | ئورنىتىش كېرەك ئەمەس؛ ھۆججەت `/home/user` دا ساقلىنىپ قالىدۇ. (كېيىن SQLite قا ئۆتكۈزۈشكە تەييار قۇرۇلما) |
| ئالدى بەت | **Vanilla JS + CSS** (React/Vue يوق) | build يوق، سۈرئەتلىك، ھەر قانداق host قا كۆچۈرۈشكە بولىدۇ |
| Dashboard | ئوخشاش vanilla JS، ئۆزىنىڭ CSS/JS ھۆججەتلىرى | يېنىك، ئۈچ تىلدا ئىشلەيدۇ |
| دەلىللەش (auth) | Session cookie + `bcrypt` پارول hash + rate limit | بىخەتەر، ساددە |

## 5. ئالدى بەت (Public Site) — بەتلەر

| بەت | URL | مەزمۇن |
|---|---|---|
| باش بەت | `/` (تىل بويىچە قايتا يوللاش) → `/ug/` | Hero (چوڭ شۇئار + CTA)، سانلار (خېرىدار/پروژې/يىل)، خىزمەتلەر قىسقىچە، تاللانما ئەسەرلەر، خېرىدار لوگوتىپلىرى، تەكلىپنامە، CTA |
| بىز ھەققىدە | `/{lang}/about` | شىركەت تارىخى، مىسىيە، گۇرۇپپا ئەزالىرى، قىممەتلەر |
| خىزمەتلەر | `/{lang}/services` | خىزمەت تىزىملىكى (بىر تەرەپ قىلىش + تەپسىلات)، باھا پىلانلىرى |
| ئەسەرلىرىمىز | `/{lang}/work` | سۈزگۈچ (category) بىلەن portfolio گالېرېيە، ھەر ئەسەرنىڭ ئۆز بېتى |
| ماقالىلەر | `/{lang}/blog` | تور بېكەت + SEO + market ماۋزۇلىرىدا يېزىقلار |
| ئالاقە | `/{lang}/contact` | فورما (ئىسىم، ئېلخەت، تېلېفون، تېما، ئۇچۇر)، خەرىتە، ئالاقە ئۇچۇرلىرى، ۋاقىت |
| 404 | `/{lang}/*` | تىلدا خاتالىق بېتى |

**ئالاھىدە دىققەت قىلىنىدىغان ئىشلار:**
- ئۇيغۇرچە ۋە ئەرەپچىدە `dir="rtl"`، ئېنگىلىزچىدە `dir="ltr"`. بارلىق CSS ئىككى يۆنىلىشنىمۇ قوللايدۇ (`margin-inline-start`، `padding-inline`، `inset-inline`).
- تىل ئالماشتۇرغۇچ ھازىرقى بەتنىڭ **شۇ بەتكە ماس كېلىدىغان** تىلغا ئۆتكۈزىدۇ (باش بەتكە ئەمەس).
- سان/ۋاقىت فورماتى ھەر تىلغا ماس (`en-US`، `ar-EG`، `ug-CN`)، ئۇيغۇرچىدا ئەرەپ-ھىندى رەقەملىرى ئەمەس، ئادەتتىكى رەقەم ئىشلىتىلىدۇ.
- ھەرىكەت: scroll-reveal، sticky navbar، hover مىكرو ئېففېكتلىرى. ھەممىسى `prefers-reduced-motion` نى ھۆرمەت قىلىدۇ.

## 6. تىل (i18n) سىستېمىسى

- تەرجىمە ھۆججەتلىرى: `i18n/{ug,ar,en}.json` — ئۇيۇل تېكىستلەر (تىزىملىك، كۇنۇپكا، فورما خاتالىقلىرى).
- **مەزمۇن** (خىزمەت ناملىرى، ئەسەر چۈشەندۈرۈشى، ماۋزۇلار) `db.json` دا ئۈچ تىللىق ئوبيېكت سۈپىتىدە ساقلىنىدۇ:
  ```json
  { "title": { "ug": "ماركا لايىھىلەش", "ar": "تصميم الهوية", "en": "Brand Identity" } }
  ```
- تىل تاللاش: URL → cookie → browser `Accept-Language` → سۈكۈتتىكى (ئۇيغۇرچە).
- SEO: ھەر بەتتە `<link rel="alternate" hreflang="ug|ar|en|x-default">`، ھەر تىلدا ئۆز `<title>` / `meta description` / OpenGraph.
- تەرجىمە يېتىشمىسە، fallback تىرتىبى: تاللانغان تىل → ئېنگىلىزچە → key.

## 7. Dashboard (ئارقا بەت باشقۇرۇش سۇپىسى)

Dashboard **ئۆزىمۇ ئۈچ تىلدا** بولىدۇ (ئوڭ/سول تەرەپ، فونت، تىل ئالماشتۇرغۇچ بىلەن).

### 7.1 بۆلەكلەر

| بۆلەك | ۋەزىپىسى |
|---|---|
| **كىرىش** | ئېلخەت + پارول، bcrypt سېلىشتۇرۇش، 5 قېتىم خاتا بولسا 15 مىنۇت توسۇش |
| **ئومۇمىي كۆرۈنۈش** | 4 كارتا (ئالاقە ئۇچۇرلىرى، ئەسەرلەر، ماقالىلەر، بېكەتكە كىرگەنلەر)، 12 ئايلىق دىئاگرامما، ئەڭ يېڭى ئۇچۇرلار، تىل بويىچە تارقىلىش |
| **خىزمەتلەر** | قوشۇش / تەھرىرلەش / ئۆچۈرۈش، ئۈچ تىلدا نام+چۈشەندۈرۈش، ئىكونكا، تەرتىپ، ئاكتىپ/پاسسىپ |
| **ئەسەرلەر (Portfolio)** | رەسىم يۈكلەش، تۈر (category)، خېرىدار، يىل، نەتىجە كۆرسەتكۈچلىرى، ئۈچ تىلدا چۈشەندۈرۈش |
| **خېرىدارلار** | لوگوتىپ، نام، تور بېكەت، تەرتىپ |
| **تەكلىپنامىلەر** | رەسىم، ئىسىم، خىزمىتى، ئۈچ تىلدا تېكىست، باھا (5 يۇلتۇز) |
| **ماقالىلەر** | ماۋزۇ، slug، مەزمۇن (markdown)، ئۈچ تىلدا، ئېلان قىلىش ھالىتى |
| **ئالاقە ئۇچۇرلىرى** | ئوقۇلغان/ئوقۇلمىغان، جاۋاب يېزىش، ئۆچۈرۈش، Excel گە چىقىرىش |
| **تەڭشەكلەر** | شىركەت نامى (3 تىل)، لوگوتىپ، ئالاقە ئۇچۇرلىرى، ئىجتىمائىي تور، ئاساسىي رەڭ، سۈكۈتتىكى تىل، SEO |
| **ئىشلەتكۈچىلەر** | admin / editor رولى، پارول ئۆزگەرتىش، يېڭى ئىشلەتكۈچى |
| **تىل تەرجىمىسى** | ئۇيۇل تېكىستلەرنى بىۋاستە تەھرىرلەش (ئېكراندىلا تەرجىمە تولۇقلاش) |

### 7.2 UI ئېلېمېنتلىرى
يېنىمۇ تىزىملىك (sidebar) + ئۈستى بار، قاراڭغۇ/ئوچۇق تېما، جەدۋەل + ئىزدەش + بەتلىك بۆلۈش، modal فورما، toast ئۇقتۇرۇش، drag تەرتىپلەش، چارتلار (ساپ SVG — سىرتقى كۈتۈپخانا يوق).

## 9. بىخەتەرلىك

bcrypt پارول hash (cost 12) · session cookie `httpOnly` + `sameSite=lax` · CSRF token · بارلىق كىرگۈزۈلگەن مەزمۇنغا `zod` غا ئوخشاش دەلىللەش · XSS ئۈچۈن ھەر دائىم escape · login rate limit · يۈكلەنگەن رەسىملەرنىڭ تىپىنى ھەقىقىي تەكشۈرۈش · admin يوللىرى middleware بىلەن قوغدىلىدۇ.

## 10. ئىشلەش سۈرئىتى ۋە SEO

- فونتلار: `font-display: swap` + ئاساسىي فونتلارغا `preload` + تىلغا قاراپ پەقەت لازىملىق فونت يۈكلىنىدۇ (ئېنگىلىزچىدە UKIJ يۈكلەنمەيدۇ).
- رەسىملەر: WebP + `loading="lazy"` + كېڭى-ئېگىزلىكى ئالدىن بېكىتىلگەن (CLS نىڭ ئالدىنى ئالىدۇ).
- Critical CSS inline، قالغانى كېيىن.
- Semantic HTML، `<h1>` بىرلا، alt تېكىست ھەر تىلدا.
- JSON-LD: `Organization` + `LocalBusiness` + `Article`.
- Lighthouse نىشان: Performance ≥ 90، Accessibility ≥ 95.

## 12. مەن سىزدىن سوراشقا تېگىشلىك ئۇچۇرلار

1. **شىركەت نامى** (ئۇيغۇرچە / ئەرەپچە / ئېنگىلىزچە) ۋە لوگوتىپ بارمۇ يوق؟
2. **رەڭ ئۇسلۇبى**: قاراڭغۇ+ئالتۇن (premium) / كۆك-بىنەپشە (digital) / ساپ ئاق-قارا (editorial) / باشقا؟
3. **Dashboard** ھەقىقىي مۇلازىمېتىر بىلەن (كىرىش + سانداندا ساقلىنىدۇ) بولسۇنمۇ، ياكى ئاددىي دېمو (localStorage) بولسۇنمۇ؟
4. **خىزمەت تۈرلىرى** — تۆۋەندىكىلەرنىڭ قايسىلىرى سىزدە بار؟ (ماركا لايىھىسى، ئىجتىمائىي تور باشقۇرۇش، Google/Meta ئىلانى، ۋىدېئو ئىشلەش، گرافىك لايىھە، تور بېكەت ياساش، ئېلان تاختىسى/چاپلاش، بايقاش)
