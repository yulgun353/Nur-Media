# نۇر مېدىيا — ئۈچ تىللىق ئىلانچىلىق تور بېكىتى + Dashboard

ئۈچ تىللىق (ئۇيغۇرچە / ئەرەپچە / ئېنگىلىزچە) ئىلانچىلىق ئاگېنتلىقى تور بېكىتى ۋە ئارقا بەت باشقۇرۇش سۇپىسى.
سىرتقى كۈتۈپخانا يوق، build قەدىمى يوق — پەقەت ساپ HTML / CSS / JavaScript.

---

## 1. ئىجرا قىلىش

```bash
cd site
node server.js            # http://localhost:4173
```

باشقا ھەر قانداق ستاتىك مۇلازىمېتىرمۇ بولىدۇ (مەسىلەن `npx serve site`).

| بەت | ئادرېس |
|---|---|
| ئالدى بەت | `/index.html` (تىل: `?lang=ug` · `?lang=ar` · `?lang=en`) |
| باشقا بەتلەر | `about.html` · `services.html` · `work.html` · `blog.html` · `contact.html` |
| **Dashboard** | `/admin.html` |

**Dashboard غا كىرىش:** `admin@nurmedia.co` / `nur2026`

## 3. فونت سىستېمىسى

ھەممە فونت لايىھە ئىچىدە ساقلىنىدۇ (`fonts/`) — CDN غا باغلىق ئەمەس، ئوفلاينمۇ ئىشلەيدۇ.

| تىل | ماۋزۇ | ئادەتتىكى تېكىست |
|---|---|---|
| **ئۇيغۇرچە** | UKIJ Ekran Bold (700) | **UKIJ Ekran** (400) |
| **ئەرەپچە** | Noto Kufi Arabic (500/700) | IBM Plex Sans Arabic (400–700) |
| **ئېنگىلىزچە** | Space Grotesk (500–700) | Inter (400–700) |

`html[lang="…"]` ئارقىلىق CSS ئۆزگەرگۈچى مىقدارلىرى (`--font-body`, `--font-head`) ئۆزلۈكىدىن ئالمىشىدۇ.
UKIJ Ekran دا `GSUB` تە `init/medi/fina/isol/rlig` بار — ھەرپ شەكلى ئۆزگەرتىش توغرا ئىشلەيدۇ.
UKIJ Ekran يەرلىك ئورنىتىلغان كومپيۇتېرلاردا `local()` ئارقىلىق ئالدى بىلەن شۇ ئىشلىتىلىدۇ.

---

## 4. تىل سىستېمىسى

- **تۇراقلىق تېكىستلەر** (تىزىملىك، كۇنۇپكا، فورما) → `js/i18n.js`
- **مەزمۇن** (خىزمەت، ئەسەر، تەكلىپنامە …) → `data/content.js` دا `{ ug, ar, en }` شەكلىدە
- تىل تاللاش تەرتىبى: URL `?lang=` → ساقلاش → browser تىلى → سۈكۈتتىكى (ئۇيغۇرچە)
- بەتلەر ئارا ھەرىكەت قىلغاندا `?lang=` ساقلىنىدۇ
- `dir` ئۆزلۈكىدىن `rtl`/`ltr` غا ئالمىشىدۇ؛ CSS پۈتۈنلەي logical property (`margin-inline`, `inset-inline-start`) ئىشلىتىدۇ

## 5. Dashboard بۆلەكلىرى

| بۆلەك | نېمە قىلىدۇ |
|---|---|
| **ئومۇمىي كۆرۈنۈش** | 4 كارتا، 12 ئايلىق دىئاگرامما (SVG)، تىل بويىچە donut، مەزمۇن تولۇقلۇقى، ئەڭ يېڭى ئۇچۇرلار |
| **خىزمەتلەر / ئەسەرلەر / خېرىدارلار / تەكلىپنامىلەر / ماقالىلەر / گۇرۇپپا** | تولۇق CRUD — قوشۇش، تەھرىرلەش، ئۆچۈرۈش، ئىزدەش |
| **ئالاقە ئۇچۇرلىرى** | يېڭى/ئوقۇلغان/جاۋاب بېرىلگەن ھالەت، جاۋاب يېزىش، CSV چىقىرىش |
| **تەڭشەكلەر** | شىركەت نامى، شۇئار، ئالاقە، ئىجتىمائىي تور، باش بەت مەزمۇنى (ھەممىسى 3 تىلدا) |
| **تەرجىمە** | ئۇيۇل تېكىستلەرنى ئېكراندىن تەھرىرلەش |
| **سانلىق مەلۇمات** | JSON چىقىرىش / كىرگۈزۈش / ئەسلىگە قايتۇرۇش |

Dashboard نىڭ ئۆزىمۇ ئۈچ تىلدا ۋە RTL/LTR نى قوللايدۇ.

---

## 6. ساقلاش (demo نەشرى)

مەزمۇن browser نىڭ **localStorage** دا (`nurmedia.content.v3`) ساقلىنىدۇ:

- Dashboard دىن ئۆزگەرتسىڭىز → ئالدى بەت دەرھال شۇ مەزمۇننى كۆرسىتىدۇ (ئوخشاش origin).
- ئالاقە فورمىسىدىن كەلگەن ئۇچۇر → Dashboard نىڭ «ئالاقە ئۇچۇرلىرى» بۆلىمىگە چۈشىدۇ.
- **مۇھىم:** ساقلاش ئىقتىدارى چەكلەنگەن مۇھىتتا (مەسىلەن sandbox iframe) ئۆزگەرتىشلەر يوقىلىشى مۇمكىن —
  شۇڭا Dashboard → «سانلىق مەلۇمات» → **JSON چىقىرىش** ئارقىلىق نۇسخا ساقلاڭ.
- ھەقىقىي مۇلازىمېتىرغا (Node + ساندان) كۆچۈرۈش ئۈچۈن `data/content.js` دىكى قۇرۇلما API غا بىۋاستە ماس كېلىدۇ.

## 7. سىناق

```bash
cd site
npm install            # بىر قېتىم (jsdom)
npm test               # 222 تەكشۈرۈش
```
